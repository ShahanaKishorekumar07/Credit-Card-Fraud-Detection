💳 Credit Card Fraud Detection
A machine learning-based web application that detects fraudulent credit card transactions using anomaly detection techniques.

🚀 Features
- Detects fraudulent credit card transactions
- User-friendly web interface using Flask
- Machine learning model for fraud prediction
- Fast and accurate transaction classification
- Easy to use and deploy

 🛠️ Technologies Used
- Python
- Flask
- Scikit-learn
- Pandas
- NumPy
- HTML
- CSS

▶️ Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/credit-card-fraud-detection.git
   ```

2. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the application:
   ```bash
   python app.py
   ```

4. Open your browser and visit:
   ```
   http://127.0.0.1:5000
   ```
